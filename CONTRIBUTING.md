# Contributions / Współpraca

Public contributions are welcome. The first milestone is stable GAMA 350 + CC1101 reception. Please avoid broad refactors until hardware decoding is confirmed.

- Attach the precise firmware, ESPHome and upstream commit versions.
- Provide reproducible tests first where possible.
- Redact actual AES keys, API keys, passwords, specific electricity use and personal information.
- Raw captured telegrams may reveal meter identity or sensitive measurements. Share only when you have the right to publish them; otherwise use sanitized, synthetic regression fixtures and clearly label them as such.
- License only your original contributions. Do not paste third-party source code unless its redistribution rights are confirmed.
- New feature proposals for other meters will be considered after hardware acceptance of GAMA 350.
